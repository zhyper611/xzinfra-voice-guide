# 舵机思考全幅摆动设计

## 目标

让是非判断装置在 AI 思考时使用与最终“是/否”位置相同的完整摆幅，同时缩小最终判断前的反向蓄力动作，使动作更明确且不产生短暂给出相反答案的观感。

## 动作规则

默认角度保持不变：是 `20°`、中立 `75°`、否 `130°`。

- 思考：在 `20°` 与 `130°` 之间连续往返，摆动速度保持现状不变。
- 判断“是”：先移动到中立右侧 `95°`，再按现有快速判断速度移动到 `20°` 并停留。
- 判断“否”：先移动到中立左侧 `55°`，再按现有快速判断速度移动到 `130°` 并停留。
- 中立、失败、退出模式和录音阶段的动作保持现状。

反向蓄力角度由中立角度加减固定 `20°` 得到，并限制在舵机配置的有效角度范围内。最终“是/否”角度仍由现有配置决定。

## 实现边界

- 实体舵机输出与网页模拟采用同一动作语义。
- 实体舵机的思考端点直接使用配置中的“是/否”角度，不新增环境变量。
- 网页模拟的思考动画端点与模拟器的“是/否”角度保持一致，不继续使用中央附近的硬编码小幅角度。
- 不修改 XZKB、模型调用、判断提示词、语音流程、三模式切换或 GPIO 按钮逻辑。

## 失败处理

沿用现有保护：过期判断结果不能打断当前动作；舵机驱动异常后熔断动作输出；无效、失败或中立结果回到中立状态。角度计算必须限制在有效范围内，不能向驱动发送越界角度。

## 测试

- 实体舵机思考序列覆盖完整的“是/否”端点。
- 判断“是”验证 `95° → 20°`，判断“否”验证 `55° → 130°`。
- 自定义角度配置验证反向蓄力不会越界。
- 网页模拟验证思考动画使用最终“是/否”端点，判断结果仍停留在目标侧。
- 运行 Python、JavaScript 全量回归、Python 编译检查和 Git 差异检查。
