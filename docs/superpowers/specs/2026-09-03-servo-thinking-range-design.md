# 舵机思考全幅摆动设计

## 目标

让是非判断装置在 AI 思考时使用与最终“是/否”位置相同的完整摆幅，同时缩小最终判断前的反向蓄力动作，使动作更明确且不产生短暂给出相反答案的观感。

## 动作规则

默认角度保持不变：是 `20°`、中立 `75°`、否 `130°`。

- 思考：在 `20°` 与 `130°` 之间连续往返，摆动速度保持现状不变。
- 判断“是”：以思考摇摆的角速度移动到中立右侧 `95°`，再按现有快速判断速度移动到 `20°` 并停留。
- 判断“否”：以思考摇摆的角速度移动到中立左侧 `55°`，再按现有快速判断速度移动到 `130°` 并停留。
- 中立、失败、退出模式和录音阶段的动作保持现状。

反向蓄力角度由中立角度加减固定 `20°` 得到，并限制在舵机配置的有效角度范围内。最终“是/否”角度仍由现有配置决定。

“与思考摇摆速度相同”按角速度定义。网页模拟根据思考单程的角度距离和动画时长计算角速度，再根据反向蓄力的实际角度距离动态计算过渡时长；默认 `20°/75°/130°` 配置下，网页思考单程为 `110°/1600ms`，反向蓄力 `20°` 对应约 `291ms`。判断结果的正向移动继续使用现有 `140ms`，不随反向时长变化。

## 实现边界

- 实体舵机输出与网页模拟采用同一动作语义。
- 实体舵机仍一次写入目标角度，不增加逐角度插值；同一舵机向不同目标运动时使用其自身机械速度，等待时间只负责动作编排。
- 实体舵机的思考端点直接使用配置中的“是/否”角度，不新增环境变量。
- 网页模拟的思考动画端点与模拟器的“是/否”角度保持一致，反向过渡时长由角度距离动态计算，不继续使用固定 `360ms`。
- 不修改 XZKB、模型调用、判断提示词、语音流程、三模式切换或 GPIO 按钮逻辑。

## 失败处理

沿用现有保护：过期判断结果不能打断当前动作；舵机驱动异常后熔断动作输出；无效、失败或中立结果回到中立状态。角度计算必须限制在有效范围内，不能向驱动发送越界角度。

## 测试

- 实体舵机思考序列覆盖完整的“是/否”端点。
- 判断“是”验证 `95° → 20°`，判断“否”验证 `55° → 130°`。
- 自定义角度配置验证反向蓄力不会越界。
- 网页模拟验证默认角度下反向时长约为 `291ms`，并验证自定义角度下仍与网页思考角速度一致。
- 网页模拟验证判断正向时长仍为 `140ms`，判断结果仍停留在目标侧。
